Focus

Measurement you can check

I work on the security of LLM and agentic systems — jailbreak evaluation, red-teaming, and the reliability of the automated judges the field uses to score both. That last part is where most of my recent work sits: automated evaluation in AI security is trusted because it produces a clean number, and that number is often wrong. I build the pipeline, then check what the pipeline is actually telling me — and publish the cases where it lied.

The route in was defensive: CompTIA CySA+, SOC telemetry pipelines, detection engineering. Building agentic platforms — multi-agent orchestration, RAG, vector stores — is what made the attack surface concrete.

Research

Judge-Shaped, Not Harm-Shaped

Preprint in prep
Jailbreak-judge measurement validity · activation-guided fuzzing

A jailbreak success judge is the thing that decides whether an attack worked, and the field reuses one small frozen classifier across many papers without re-validating it. I found it inflates success by rewarding jailbreak-shaped surface form — persona and roleplay framing — over actual harmful content.

  • Built a stricter two-stage replacement (refusal pre-filter + anti-roleplay rubric judge). It did not fully work — it still passed a completion that refuses the request and offers crisis-support resources. The failure mode survives a fix built specifically to stop it.
  • Secondary result, reported as an honest null: activation-guided span mutation shows no consistent advantage over uniform mutation on either target tested — with the mechanism independently confirmed engaged, so the null is not an artifact of the method quietly doing nothing.
  • All results smoke-scale (n=5 per condition); the planned larger matrix did not run — free-tier compute was exhausted first, stated plainly rather than disguised.

AJF reproduction

Reproduced
Independent reproduction · adaptive jailbreak framework (arXiv:2505.23404)

Full reproduction of a 2026 jailbreak paper's mechanism — prompt mutation, binary-tree encoding, dual-cipher output encryption, and its capability-classification probe — run against three local models, plus an ablation and a defense the original paper names in its own limitations but never evaluates.

  • The same measurement failure recurred independently here: a self-judge was wrong in both directions on the same five prompts — scoring refusals as compliance, and scoring real compliance as refusal. Every result was re-checked by hand and the corrected verdicts committed alongside the originals.
  • Also caught a bug in my own harness that was corrupting the data before scoring — documented rather than quietly fixed, because it changed what earlier results meant.

Attacker architecture over model size

In progress
Agentic-AI-security benchmark · OWASP FinBot CTF · scored by the target's own detector

A harness that runs local LLM attackers against a deliberately-vulnerable multi-agent target (OWASP FinBot CTF) across three attacker architectures — single-shot, an agentic loop that reads and adapts, and a Supervisor→Generation→Reflection→Evolution multi-agent pipeline. Success is scored by the target's own automatic exploit detector, not by the attacker grading itself.

  • Single-shot never engaged the workflow. The multi-agent attacker (llama3.1) ran a real chain — recon, policy-exception social engineering, adaptation — and still failed, but for a higher-level reason: strategic drift, not a weaker model. Attacker architecture dominates model choice.
  • Honest state: the orchestration is wired, but the four agent prompts — the ideation design that actually decides the attack — are still open. No exploit is claimed; the result so far is a documented rung-0 failure with its cause named.

Security audit of a deployed multi-agent (A2A) platform

Audited authorization on a deployed agent-to-agent platform against the 14-row protocol threat matrix of Ferrag et al. (ICT Express 2025, arXiv:2506.23260), under an evidence bar: a control is only marked absent after both a recorded static search and a runtime probe — never by grep alone.
